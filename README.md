#  NekoBootstrap

**NekoBootstrap** is a responsive, front-end web application developed for a themed cat café concept. Built using HTML5, CSS3, JavaScript, and Bootstrap, this project serves as a structured static implementation showcasing modern layout design, interactive components, and user flows.

 **Live Demo:** [Check it out on GitHub Pages](🌐 **Live Demo:** [Check it out on GitHub Pages](https://sarareis50.github.io/neko-bootstrap/)) *(update the link if your repository has a different name)*

---

##  Pages & Structure

* **Home (`index.html`):** Main landing page featuring the café's brand identity, introduction to the slow-living concept, and navigation to key sections.
* **Menu (`Menu.html`):** Interactive display of specialty coffees, pastries, and treats available at the café.
* **Reservations (`Reservas.html`):** Booking interface designed for visitors to reserve a table and schedule time with the resident cats.
* **Contacts (`Contactos.html`):** Information page complete with inquiry details and location references.

---

##  Tech Stack & Structure

* **Markup:** HTML5
* **Styling:** CSS3, Bootstrap Framework
* **Scripting:** JavaScript
* **Directory Layout:**
  * `/assets` — Images, icons, and media files
  * `/css` — Custom stylesheets
  * `/js` — Custom scripts and interactivity logic

##  Getting Started Locally

To run this project locally on your machine:

1. Clone or download this repository into your local server environment (such as `htdocs` for XAMPP) or open it directly in your code editor (e.g., VS Code).
2. Open `index.html` in your web browser or run it via a local development server (like Live Server).
